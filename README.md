# كليك — موقع تسويقي رقمي

واجهة عربية متجاوبة لوكالة «كليك» تعرض خدمات تصميم وبرمجة المنتجات الرقمية بأسلوب بصري احترافي. يركز الموقع على تقديم الخدمة بوضوح من خلال سلايدر صور تفاعلي، وحركات دخول وتمرير محسوبة، وتجربة استخدام مناسبة للجوال وسطح المكتب.

## التقنيات

- TanStack Start وReact 19
- TanStack Router
- TypeScript
- Tailwind CSS 4 مع أنماط CSS مخصصة
- Lucide React للأيقونات الوظيفية
- Netlify للنشر والاستضافة

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

يفتح خادم التطوير الافتراضي على المنفذ المحدد في إعدادات Vite. للبناء الإنتاجي استخدم `pnpm build`.

### تسجيل الدخول بجوجل عبر Express

لو تريد أن يظهر اسم نطاقك/تطبيقك في شاشة Google بدل اسم مشروع Supabase، شغّل
الخادم الاختياري بعد إعداد متغيراته:

```bash
npm run build
npm run start:express
```

التفاصيل الكاملة في [`GOOGLE_EXPRESS_SETUP.md`](./GOOGLE_EXPRESS_SETUP.md)،
ومتغيرات الخادم في [`.env.server.example`](./.env.server.example). لا تضع أسرار
Google أو `service_role` في متغيرات `VITE_`.

## أهم المسارات

- `src/routes/index.tsx`: الصفحة الرئيسية وتفاعلات السلايدر والقائمة.
- `src/styles.css`: الهوية البصرية، الحركة، والتجاوب.
- `public/assets/`: شعار كليك وصور الخدمات المحلية.
- `src/routes/__root.tsx`: بيانات الصفحة وإعداد اللغة العربية.

## الصور

تُحفظ صور الخدمات داخل المشروع لتفادي الاعتماد على روابط خارجية أثناء العرض، مع نصوص بديلة عربية لكل صورة.
